# Security Policy

Maintaining security across the app is really important. If anything is found, please report it promptly.
If vulnerability is found within the app, you can report it by following the following steps. 

To report a security issue, navigate to Security and Quality:
<img width="3420" height="1554" alt="image" src="https://github.com/user-attachments/assets/63b94367-80cc-410f-96d8-80776c845f19" />

Then click Report a Vulnerability:
<img width="3420" height="1554" alt="image" src="https://github.com/user-attachments/assets/1db0d829-daec-4473-bbec-277510a2c114" />

Fill out the details and submit the report. 
<img width="1708" height="964" alt="image" src="https://github.com/user-attachments/assets/fc2d179a-e750-4b0f-939b-7df1ea619e90" />

Please include a description of the issue, the steps you took to create the issue, affected versions, and, if known, mitigations for the issue.
All vulnerabilities are taken seriously and will be patched as soon as possible.

If reporting through GitHub is not possible, please email shariq.charolia@gmail.com with a description of the issue, the steps you took to create the issue, affected versions, and, if known, mitigations for the issue.
